  1단계: 랜드마크 추출 (VideoAnalyzer.tsx)                             
                                                                       
  MediaPipe 홍채 랜드마크 인덱스                                       
                                                                       
  ┌──────┬────────┬──────┐                                             
  │  눈   │ 인덱스  │ 방향  │                                             
  ├──────┼────────┼──────┤                                             
  │ 좌안  │ 469    │ 좌끝  │                                             
  ├──────┼────────┼──────┤                                             
  │ 좌안  │ 470    │ 상단  │                                             
  ├──────┼────────┼──────┤                                             
  │ 좌안  │ 471    │ 우끝  │
  ├──────┼────────┼──────┤                                             
  │ 좌안  │ 472    │ 하단  │                                  
  ├──────┼────────┼──────┤                                             
  │ 우안  │ 474    │ 좌끝  │
  ├──────┼────────┼──────┤                                             
  │ 우안  │ 475    │ 상단  │                                  
  ├──────┼────────┼──────┤
  │ 우안  │ 476    │ 우끝  │
  ├──────┼────────┼──────┤                                             
  │ 우안  │ 477    │ 하단  │
  └──────┴────────┴──────┘                                             
                                                            
  좌표계: 정규화(0~1), 픽셀 변환 시 × videoWidth 또는 × videoHeight    
  
  홍채 중심 (Centroid)                                                 
                                                            
  4개 랜드마크의 산술 평균:                                            
                                                            
  irisCenter.x = (lm[469].x + lm[470].x + lm[471].x + lm[472].x) / 4   
  irisCenter.y = (lm[469].y + lm[470].y + lm[471].y + lm[472].y) / 4   
  
  홍채 폭 (px)                                                         
                                                            
  leftIrisWidth  = |lm[469].x − lm[471].x| × videoWidth                
  rightIrisWidth = |lm[474].x − lm[476].x| × videoWidth     
                                                                       
  동공 크기 Proxy (타원 면적 근사)
                                                                       
  MediaPipe는 동공/홍채를 구분하지 않으므로 iris 타원 면적을 동공 크기의 대리 지표로 사용:
                                                                       
  leftIrisHeight  = |lm[470].y − lm[472].y| × videoHeight   
  leftPupilProxy  = leftIrisWidth × leftIrisHeight
                                                                       
  rightIrisHeight  = |lm[475].y − lm[477].y| × videoHeight
  rightPupilProxy  = rightIrisWidth × rightIrisHeight                  
                                                                       
  ▎ 조절(accommodation) 증가 → 동공 수축 → 홍채 상대 면적 증가.        
  ▎ 이 비율 변화를 조절력 추정에 사용.

  2단계: 자동 보정 (useBinocularLogic.ts)                              
                                                            
  2-1. Pixel → mm 변환 계수 (iris 기준)
                                                             
  인간 홍채 수평 지름은 인종·성별 무관하게 11.7mm 로 일정:             
                                                                       
  rawPixelToMm = 11.7 / avgIrisWidthPx                                 
               = 11.7 / ((leftIrisWidth + rightIrisWidth) / 2)         
  
  프레임 간 노이즈 제거를 위해 지수 이동 평균(EMA, τ = 0.05) 적용:     
                                                            
  pixelToMm[t] = pixelToMm[t−1] × 0.95 + rawPixelToMm × 0.05           
                                                                       
  (초기값 0일 때 첫 번째 유효 측정값을 그대로 사용. fallback: 0.45)    
                                                                       

  2-2. 거리 추정                                                       
                                                            
  웹캠 FOV 60°를 기준으로 focal length를 픽셀 단위로 계산:             
  
  focalLengthPx = (videoWidth / 2) / tan(30° × π/180)                  
                = (videoWidth / 2) / tan(π/6)                          
  
  ▎ 예: videoWidth=1280 → focalLengthPx ≈ 1109 px                      
                                                            
  홀로그래피 투영 공식(pinhole camera model)으로 거리 추정:            
                                                            
  distanceCm = (11.7mm × focalLengthPx) / (avgIrisWidthPx × 10)        
                                                                       
  ▎ 분모 × 10: mm → cm 단위 환산                                       
                                                                       
  EMA 안정화 (τ = 0.05):                                               
                                                            
  distanceCm[t] = distanceCm[t−1] × 0.95 + rawDistanceCm × 0.05        
                                                                       
  2-3. IPD 자동 측정
                                                                       
  매우 느린 EMA (τ = 0.03) — 순간 값보다 장기 평균이 IPD에 가깝기 때문:
  
  ipdMm[t] = ipdMm[t−1] × 0.97 + currentPDMm × 0.03                    
                                                                       


  ---                                                                  
  3단계: 실시간 PD / Velocity / Symmetry                               
                                                                       
  EMA 스무딩 (α = 0.3)                                      
                                                                       
  smoothLeftX[t]  = smoothLeftX[t−1] + 0.3 × (rawLeftX  −
  smoothLeftX[t−1])                                                    
  smoothRightX[t] = smoothRightX[t−1] + 0.3 × (rawRightX −  
  smoothRightX[t−1])                                                   
                                                            
  동공간거리 PD (mm)                                                   
                                                            
  currentPDmm = |smoothLeftX − smoothRightX| × pixelToMm
                                                                       
  버전각 속도 Velocity (mm/s)                                          
                                                                       
  velocityMmPerSec = (currentPDmm − prevPDmm) / dt                     
                                                                       
  - 양수: PD 증가 = 개산(divergence)                                   
  - 음수: PD 감소 = 폭주(convergence)                                  
                                                                       
  대칭성 Symmetry (%)                                                  
  
  좌안/우안이 얼마나 균등하게 움직이는지 평가:                         
                                                            
  speedLeft  = |Δ smoothLeftX  × pixelToMm / dt|                       
  speedRight = |Δ smoothRightX × pixelToMm / dt|                       
  totalSpeed = speedLeft + speedRight
                                                                       
  if totalSpeed > 1.0 mm/s:                                            
      symmetry = (1 − |speedLeft − speedRight| / totalSpeed) × 100 else:                                                                
      symmetry = 100  (정지 상태는 완전 대칭으로 처리)      
                                                                       


  ---                                                       
  4단계: Break Point 감지 (clinicalCalculations.ts)                    
                                                                       
  녹화된 전체 샘플에서 수렴/개산 break 및 recovery 시점을 자동 추출.
                                                                       
  5-sample Sliding Window Velocity                                     
                                                                       
  windowedVelocity[i] = (pdMm[i] − pdMm[i−5]) / (t[i] − t[i−5])  [mm/s]
                                                                       
  Convergence Break 감지 조건
                                                                       
  PD가 감소 중(폭주 진행)이다가 급반전하는 시점:                       
  
  prev_velocity < −0.5 mm/s    (폭주 진행 중)   AND                                                                  
  curr_velocity > +2.0 mm/s    (급격한 반전 = fusion break)
                                                                       
  여러 번 감지되면 최대 편차(baseline으로부터 가장 멀리 이탈한) 선택.  
                                                                       
  Divergence Break 감지 조건                                           
                                                            
  prev_velocity > +0.5 mm/s    (개산 진행 중)   AND                                                       
  curr_velocity < −2.0 mm/s    (급격한 반전 = divergence break)
                                                                       
  Recovery 감지
                                                                       
  Break 이후 PD가 baseline ± 1mm 이내로 복귀하는 첫 번째 시점:         
  
  |pdMm[i] − baselinePd| < 1.0 mm  →  recovery                         
                                                                       
  mm → 프리즘 디옵터 변환                                              
                                                                       
  Δ = deviation_mm / (distanceCm × 0.1)                                
                                                                       
  ▎ 예: 50cm에서 5mm 편차 → 5 / (50 × 0.1) = 1.0Δ                      
                                                                       
  Fallback (break 미감지 시)                                           
                                                            
  convergenceBreak  = baselinePd − minPd                               
  convergenceRecovery = convergenceBreak × 0.7
                                                                       
  divergenceBreak  = maxPd − baselinePd                     
  divergenceRecovery = divergenceBreak × 0.7

  5단계: 임상 지표 계산 (clinicalCalculations.ts)
                                                                       
  입력: 전체 AnalysisSample[] + userAge?
                                                                       
  Baseline PD                                                          
                                                                       
  baselineCount = min(30, max(5, floor(N × 0.1)))                      
  baselinePd    = mean(samples[0..baselineCount].pdMm)                 
                                                                       
  ---                                                                  
  5-1. 사위 Phoria (Δ)                                                 
                                                                       
  (1차: PD 평균 편차 기반. 2차에서 커버테스트로 대체 예정)
                                                                       
  pdDeviation = mean(all samples.pdMm) − baselinePd         
                                                                       
  distPhoria = pdDeviation / (distanceCm × 0.1)        [원거리]        
  nearPhoria = (pdDeviation × 1.5) / (distanceCm × 0.1)  [근거리: 임시 계수]                                                                
                                                            
  ---                                                                  
  5-2. 폭주 범위 PRC / NRC                                  
                          
  Break point 감지 결과를 그대로 사용:
                                                                       
  distPRC = "convergenceBreakΔ / convergenceRecoveryΔ"
  distNRC = "divergenceBreakΔ / divergenceRecoveryΔ"                   
                                                            
  근거리 PRC/NRC (1차: 원거리 비율 기반, 2차에서 실측 대체):           
                                                            
  nearPRC = distPRC × 1.3  (근거리 폭주력이 원거리보다 큼)             
  nearNRC = distNRC × 0.8  (근거리 개산 여유가 원거리보다 작음)        
                                                                       
  ---                                                                  
  5-3. 조절력 PRA / NRA — 동공 기반 추정                               
                                                                       
  근반사 3요소: 조절(accommodation) + 폭주(convergence) + 동공 수축(miosis)은 연동.                                                 
  → 폭주 시 동공이 수축하므로 iris proxy 면적 감소를 조절 변화의 대리지표로 사용.                                                         
                                                            
  Baseline Proxy: 처음 10% 샘플 평균                                   
                                                            
  수축 비율:                                                           
  contractionRatio = (baselineProxy − minProxy) / baselineProxy
                                                                       
  이완 비율:                                                           
  dilationRatio = (maxProxy − baselineProxy) / baselineProxy
                                                                       
  조절량 추정 (K = 2.5D, 문헌 기반: 동공 1mm 변화 ≈ 2–3D):  
  PRA = −(K × contractionRatio)    [minus lens 상당, 음수]             
  NRA =  K × dilationRatio          [plus lens 상당, 양수]
                                                                       
  ▎ 한계: 조명 변화·감정에 의한 동공 변화와 구분 불가. UI에 "추정치" 표기 필요.                                                           
                                                                       
  ---                                                                  
  5-4. AC/A Ratio — Heterophoria Method                     
                                                                       
  ipdCm = mean(|leftX − rightX| × pixelToMm) / 10      [cm 단위]
  nearDiopter = 100 / min(distanceCm, 100)    [검사 거리의 조절 요구량 D]                                                       
                                                                       
  AC/A = ipdCm + nearDiopter × (nearPhoria − distPhoria)               
                                                            
  ▎ 단위: Δ/D (프리즘 디옵터 / 조절 디옵터)                            
                                                            
  ---                                                                  
  5-5. NPC (근거리폭주근점) — cm                            
                                                                       
  Convergence break 시 vergence angle로 거리 역산:
                                                                       
  NPC(cm) = IPD(mm) / convergenceBreakΔ                     
                                                                       
  ▎ 예: IPD = 63mm, break = 30Δ → NPC = 63/30 ≈ 2.1cm                  
                                                                       
  ---                                                                  
  5-6. 최대 조절력 (D)                                      
                                                                       
  나이 입력 시 — Hofstetter Average Formula:
                                                                       
  maxAccom = 18.5 − 0.3 × age
