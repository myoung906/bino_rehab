# v1.1: 문헌에 근거한 양안시 검사와 검증 계획

> 문서 작성일: 2026-10-04
>
> 대상 브랜치: `test/v1.1`
>
> 기준 커밋: `ce0bce0ae52d776b3ffc57d5012eda616ac6d2d2`
>
> 이 문서는 문헌 검토와 사용자 인터뷰로 정리한 구현 계획이다. 이번 커밋은 문서만 추가하며, 앱 구현과 임상 검증은 후속 작업이다.

## 1. 고증 결과와 구현 방향

**전면 카메라와 행동 안내만으로 11개 항목을 모두 정량 측정할 근거는 부족합니다. 우선 NPC와 단안 조절근점을 측정하고, 사위는 가림 전후 움직임을 관찰·기록하는 방향이 타당합니다.**

이번 검토에서는 AOA 임상지침 원문, 대학 임상실습 자료, 스마트폰 안위·NPC 측정 연구, 조절력 측정 연구, Apple·MediaPipe 공식 자료를 확인했습니다. 문헌 검토 당시 저장소와 배포 상태는 변경하지 않았으며, 테스트 브랜치도 아직 생성하지 않았습니다.

인터뷰로 확정한 조건은 다음과 같습니다.

- 검사자가 보조하고, 표준 검사값과 같은 사람의 앱 결과를 비교한다.
- 자·종이 표적·가림판·거치대를 허용한다.
- 현재 웹·Capacitor 구조의 범용 전면 RGB 카메라를 사용한다.
- 사위는 관찰부터 검증하며, 첫 버전에서 카메라 기반 Δ 값을 표시하지 않는다.
- 첫 검증은 원거리 굴절교정 상태와 검사 이해도를 확인한 성인 대상으로 한다.

OEP 21-point는 검사 조건과 해석 체계를 포함합니다. 이번 버전은 요청한 11개 항목을 다루는 실험용 검사 앱으로 명시하고, 전체 OEP 검사를 재현했다고 표시하지 않습니다. [OEPF의 검사 체계 설명](https://www.oepf.org/history/)

## 2. 11개 항목별 측정 원리와 가능 범위

아래의 ‘가능’은 **검사 절차를 구현할 수 있다는 뜻**입니다. 앱의 정확도가 이미 입증됐다는 뜻은 아닙니다.

| 항목 | 필요한 검사 원리 | 전면 RGB 카메라·기본 도구로 할 수 있는 범위 |
|---|---|---|
| ① 원거리 사위 | 원거리 표적 주시 중 융합을 차단하고 편위 평가 | 외부 원거리 표적을 보면서 가림 전후 움직임 기록. Δ 정량화는 보류 |
| ② 원거리 PRC | 원거리 주시를 유지하며 BO 프리즘으로 폭주 요구량 증가 | 프리즘 없이 동일한 검사값 산출 불가 |
| ③ 원거리 NRC | 원거리 주시를 유지하며 BI 프리즘으로 개산 요구량 증가 | 프리즘 없이 동일한 검사값 산출 불가 |
| ④ 근거리 사위 | 정해진 근거리의 조절 표적 주시 중 융합 차단 | 교대 가림 안내와 재주시 움직임 기록. Δ 정량화는 보류 |
| ⑤ 근거리 PRC | 고정된 근거리에서 BO 부하를 증가시키고 흐림·복시·회복 기록 | 단순히 표적을 가까이 이동하는 것으로 대체 불가 |
| ⑥ 근거리 NRC | 고정된 근거리에서 BI 부하를 증가시키고 흐림·복시·회복 기록 | 단순히 먼 곳이나 옆을 보게 하는 것으로 대체 불가 |
| ⑦ 근거리 PRA | 양안 주시·거리 유지 상태에서 마이너스 렌즈를 추가 | 렌즈 없이 동일한 검사값 산출 불가 |
| ⑧ 근거리 NRA | 양안 주시·거리 유지 상태에서 플러스 렌즈를 추가 | 렌즈 없이 동일한 검사값 산출 불가 |
| ⑨ NPC | 표적을 접근·후퇴시키며 융합 이탈과 회복 시점의 거리 측정 | 우선 구현할 후보. 거리 실측과 검사자 관찰을 함께 기록 |
| ⑩ AC/A | 독립적으로 측정한 원·근거리 사위와 IPD로 계산하거나, 렌즈 전후 사위 변화 측정 | 표준 검사 입력값으로 계산 가능. 현재 카메라 자료만으로 자동 산출은 보류 |
| ⑪ 최대조절력 | 단안으로 표적을 접근시키며 최초 지속 흐림의 거리 측정 | 주관적 push-up 조절력으로 구현 가능. 카메라가 수정체 조절량을 직접 측정하는 것은 아님 |

AOA 지침은 가림 검사, 프리즘을 이용한 융합버전스 검사, 렌즈를 이용한 상대조절 검사, NPC, 단안 조절력 검사를 서로 다른 절차로 설명합니다. **IPD는 기하학적 입력값이지, 이 검사들을 대신하는 측정값이 아닙니다.** [AOA 임상지침, 인쇄면 26–31쪽](https://www.aoa.org/AOA/Documents/Practice%20Management/Clinical%20Guidelines/Consensus-based%20guidelines/Care%20of%20Patient%20with%20Accommodative%20and%20Vergence%20Dysfunction.pdf)

행동 안내의 의미도 구분해야 합니다.

- **가까이 보기:** 조절과 폭주가 함께 변합니다. NPC 검사에는 활용할 수 있지만 PRC나 PRA를 따로 측정하지는 못합니다.
- **옆 보기:** 주로 양쪽 눈의 공동운동을 유발합니다. NRC 검사와 다릅니다.
- **교대로 가리기:** 융합을 차단하므로 편위 관찰에 적합합니다. 먼저 cover–uncover를 수행해야 현성 편위와 잠복 편위를 구분할 수 있습니다. 교대 가림에서 보이는 전체 편위를 무조건 ‘사위’로 표시하면 안 됩니다. [AAO 가림 검사 설명](https://eyewiki.aao.org/Cover_Tests)

일반 화면에 두 표적을 그리는 것만으로는 양쪽 눈에 서로 다른 자극을 독립적으로 제공하지 못합니다. 별도의 시각 분리나 자유융합 방식은 다른 검사법으로 검증해야 하므로 이번 범위에서는 제외합니다.

## 3. 스마트폰 연구에서 채택할 근거와 한계

**NPC에는 현재 앱과 가까운 선행 연구가 있습니다.**

2025년 MobileS 연구는 전면 RGB 카메라와 MediaPipe를 사용했습니다. 사용자가 화면 표적을 주시하며 휴대폰을 접근시키고, 홍채 중심 간격·얼굴까지의 거리·코 기준 눈 움직임으로 NPC를 판단했습니다. 성인 86명에서 RAF ruler와 비교한 결과는 다음과 같습니다.

- 상관계수 `r = 0.74`, 일치도 `ICC = 0.73`
- 앱 결과의 **83.72%가 기준 검사와 ±3cm 이내**
- 논문의 10cm 기준 분류에서 민감도 76%, 특이도 85%

이는 구현 가능성을 뒷받침하지만, 정밀한 임상 측정과의 동등성을 입증하지는 않습니다. 연구는 전문가 감독하에 진행됐으며 당시 Android 구현이었습니다. 검출 임계값도 원문만으로 완전히 재현하기 어려워, 해당 앱과 동일한 알고리즘이라고 주장하지 않습니다. [MobileS 원문](https://www.mdpi.com/2813-1053/3/2/8)

**사위 정량화 연구는 전면 카메라의 단순 홍채 추적과 다릅니다.**

EyeTurn 연구는 후면 카메라와 플래시로 **각막 반사점과 홍채 중심의 상대 위치**를 측정했습니다. 근거리 사위 비교는 40cm, 고정된 머리 위치, 검사자의 교대 가림, 가림 해제 직후 프레임 선택이라는 조건에서 수행됐습니다. 14명의 Modified Thorington 비교에서 RMS 차이는 1.7Δ였지만, 별도 사시 환자 비교에서는 RMS 차이가 6.8Δ였습니다. 이 성능을 현재 MediaPipe 전면 카메라 코드에 적용할 수 없습니다. [EyeTurn 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC6369861/)

**최대조절력은 주관적 검사로 구현할 수 있습니다.**

단안 push-up 검사는 반대 눈을 가리고 작은 글자 표적을 접근시킨 뒤, 최초 지속 흐림의 거리를 측정합니다. 원거리 굴절교정 상태에서 `AA(D) ≈ 100 / 근점거리(cm)`로 계산합니다. 연구에서는 흐림이 2–3초 동안 해소되지 않는지를 확인했습니다. 측정법마다 차이가 있으므로 결과명은 ‘단안 push-up 조절력’으로 표시합니다. [조절력 측정법 비교 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC4131318/)

**iPhone의 하드웨어 사양과 앱의 측정 성능도 구분합니다.**

iPhone 12 mini는 12MP TrueDepth 전면 카메라를 갖추지만, 웹에서 얻는 영상 해상도·프레임률은 실제 스트림에서 확인해야 합니다. 이번 버전은 RGB 영상만 사용합니다. [Apple 사양](https://support.apple.com/en-ae/111877)

MediaPipe는 홍채 기반 거리 추정의 가능성을 설명하면서도, **홍채 추적 자체가 시선 방향을 추정하는 것은 아니라고 명시**합니다. 홍채 지름 11.7mm도 개인별 실측 상수가 아니라 약 `11.7 ± 0.5mm`의 집단 가정입니다. [MediaPipe 공식 설명](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/iris.md)

## 4. v1.1의 함수와 검사 흐름

실행 단계에서는 `main`의 확인된 커밋 `ce0bce0`를 기준으로 **`test/v1.1`** 브랜치를 만들고, 모든 변경과 검증을 해당 브랜치에서 수행합니다. 기존 배포는 유지합니다.

**측정 모델 수정**

- 프레임상의 홍채 중심 간격을 ‘영상상 중심 간격’으로 취급하고, 원거리 IPD와 구분합니다.
- 얼굴–카메라 거리와 눈–주시표적 거리를 별도 입력으로 관리합니다. 가까이 있는 카메라로 원거리 주시를 촬영할 때 둘은 다릅니다.
- 기존 근거리 배율, recovery 0.7배, 홍채 면적 기반 PRA/NRA, IPD/추정 PRC 기반 NPC 계산을 제거합니다.
- 나이 기반 조절력 예상치는 참고값으로 분리하고 측정 결과에 넣지 않습니다.
- 화면 미러링과 해부학적 좌우를 분리합니다. 가림·추적 소실 구간에서는 좌표를 유효한 눈 측정값으로 사용하지 않습니다.

**핵심 함수**

| 함수 역할 | 입력과 출력 |
|---|---|
| 거리 보정 | 알려진 거리의 홍채 폭으로 보정계수를 계산하고, 별도 거리에서 오차 검증 |
| 가림 검사 분석 | 검사 단계·눈별 유효 프레임·검사자 이벤트 → 재주시 궤적과 관찰 가능 여부. Δ 출력 없음 |
| NPC 결과 계산 | 검사자가 확인한 break/recovery 시점과 자로 측정한 거리 → 반복별 NPC 결과 |
| 단안 조절력 계산 | 눈별 지속 흐림 거리·교정 상태 → 주관적 push-up 조절력 |
| calculated AC/A | 표준검사로 얻은 원·근거리 사위, 원거리 IPD, 근거리 → 계산값과 입력 출처 |
| 전체 결과 구성 | 11개 항목별 값·단위·방법·측정 상태·실패 사유 |

AC/A는 내사위를 양수, 외사위를 음수로 통일하고 다음 식을 사용합니다.

`AC/A = IPD(cm) + 근거리(m) × [근거리 사위(Δ) − 원거리 사위(Δ)]`

예를 들어 IPD 6cm, 근거리 40cm, 원거리 −2Δ, 근거리 −10Δ이면 `2.8Δ/D`입니다. 현재 코드의 `100/거리(cm)`를 곱하는 방식은 수정합니다. 원·근거리 사위가 없으면 계산하지 않습니다. [AOA 임상지침, 인쇄면 30–31쪽](https://www.aoa.org/AOA/Documents/Practice%20Management/Clinical%20Guidelines/Consensus-based%20guidelines/Care%20of%20Patient%20with%20Accommodative%20and%20Vergence%20Dysfunction.pdf)

**검사 절차**

- 준비: 교정 상태 기록, 카메라 품질 확인, 자로 거리 확인. 기본 근거리 검사는 40cm로 통일합니다. 50cm 검사는 별도 조건으로 기록합니다.
- 가림: 원거리 외부 표적, 근거리 표적 순으로 cover–uncover 후 교대 가림. 눈마다 4초 안내를 사용하고 실제 가림·해제 시점은 검사자가 표시합니다.
- NPC: 중앙 표적을 약 50cm에서 천천히 접근·후퇴시킵니다. 복시 보고와 검사자의 눈 이탈 관찰을 따로 기록하고, break/recovery 거리는 자로 확인합니다.
- 조절근점: 오른눈·왼눈을 각각 검사합니다. 종이 글자 표적을 사용하고 최초 지속 흐림의 거리를 기록합니다.
- 가림 검사 → NPC → 조절근점 순서로 진행하고, 각 검사군 사이에는 3분간 원거리 주시 휴식을 둡니다. 반복 횟수는 각 검사당 3회로 고정합니다.

카메라 거리 추정은 보조값으로 기록하고, 첫 검증의 거리 기준값은 자 측정값으로 사용합니다. 자동 NPC 후보 시점은 연구 기록에만 남기며 검사자가 확인한 endpoint를 대체하지 않습니다.

6개 PRC/NRC·PRA/NRA 항목은 **‘추가 광학 도구 필요’**로 표시합니다. 가림 결과의 숫자 사위도 미측정으로 남기고, 표준 검사값은 별도 비교 입력란에 보존합니다. 결과에는 `measured`, `derived`, `unavailable`, `invalid`, `censored` 상태를 둡니다.

## 5. 검증과 완료 기준

**계산 검증**

- AC/A의 단위·부호와 위 예제, 조절근점 10cm → 10D를 테스트합니다.
- 거리 0, 누락값, 비유한수, 미교정 조건에서 숫자를 만들어내지 않습니다.
- 끝까지 복시나 흐림이 없으면 정확한 근점 대신 측정 범위 한계로 기록합니다.
- 추적 소실과 눈 이탈, 재주시 움직임과 머리 이동을 구분하는 실패 시나리오를 확인합니다.

**기기 검증**

- iPhone 12 mini와 다른 전면 RGB 기기에서 실제 해상도·프레임률·프레임 간격을 기록합니다.
- 고정 거리, 접근·후퇴, 안경 반사, 한쪽 눈 가림, 근거리 얼굴 잘림을 확인합니다.
- 30·40·50cm에서 거리 모델을 보정하고, 보정에 쓰지 않은 20·60cm에서 오차를 평가합니다. 근점 영역의 정확도는 별도로 확인합니다.

**표준 검사 비교**

- 우선 성인 20명의 탐색적 자료를 수집합니다. 이는 임상 정확도 인증을 위한 표본 수가 아닙니다.
- NPC는 같은 표적·거리 기준을 사용한 ruler 검사와 비교합니다.
- 조절력은 같은 단안 push-up 검사와 비교합니다.
- 가림 영상은 검사자가 평가하고 표준 cover test 결과와 대응시킵니다.
- 평균 편향, MAE, Bland–Altman 95% 일치한계, 반복성, 측정 실패율을 보고합니다. 상관계수만으로 정확도를 판정하지 않습니다.

문헌·수식·검사 조건·한계는 브랜치 내 연구 문서에 출처와 함께 남깁니다. 비교 결과는 JSON/CSV로 내보내고, 검사 영상 저장은 기본적으로 꺼두되 검증자가 명시적으로 켤 수 있게 합니다.

**완료 기준은 검사별 근거와 입력 출처가 추적되고, 측정할 수 없는 항목에는 값이 생성되지 않으며, NPC·단안 조절근점·가림 관찰을 표준 검사와 비교할 수 있는 것입니다.**
